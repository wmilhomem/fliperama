# Instruções do projeto

- Sempre atualize o GitHub ao concluir uma alteração: rode as verificações, faça commit e envie para `origin main`.
- Antes do commit, rode `npm run lint` e `npm run build`.
- Nunca faça commit de segredos, chaves ou arquivos de ambiente.
- Mantenha os jogos existentes e o hub funcionando; novos jogos devem seguir o contrato `GameModule`.
